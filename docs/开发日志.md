### 三、今日知识点

- **验证码种类**：图形验证码（Hutool/EasyCaptcha）、短信验证码（阿里云/腾讯云 SMS）、行为验证码（极验/腾讯防水墙）。
- **统一返回 Result 模式**：企业中各 Controller 返回自定义 `Result` 类，规范 code/message/data 结构。
- **包分类**：`Result` 这类基础公共类放 `common` 包，而非 `po`/`dto`/`vo`。
- **knife4j 4.x 注解**：对应 OpenAPI 3，用 `io.swagger.v3.oas.annotations.*` 的 `@Tag`/`@Operation`/`@Parameter`/`@Schema`，不是老 Swagger 2 的 `@Api`/`@ApiOperation`。
- **手机号正则**：`^1[3-9]\d{9}$`，注意 `String.matches()` 是全匹配语义，且要先判空短路。
- **Redis 序列化**：默认 JDK 序列化会乱码、体积大、要求 Serializable，故自定义成 JSON。
- **Redis 五种数据结构**：String（`opsForValue`，存 token/验证码最常用）、Hash、List、Set、ZSet。
- **自动配置退让**：`@ConditionalOnMissingBean` 机制，自己定义同名 Bean 即可覆盖 Spring Boot 默认配置。
- **RabbitMQ 依赖**：`spring-boot-starter-amqp` 自动配置 `RabbitTemplate`（发消息）和 `@RabbitListener`（收消息），发字符串消息默认不乱码，零配置即可用。

### 四、遇到的问题与解决

1. **`MissingServletRequestParameterException`**：`@RequestParam("phone")` 要求必传 phone 参数，漏传就报错。解决：请求带 `?phone=13800138000`。
2. **`HttpMediaTypeNotAcceptableException`（406）**：
   - 原因一：旧代码 Controller 返回 `String`（`text/plain`），而 knife4j 的 `Accept` 是 `application/json`，内容协商失败。
   - 原因二：新建的 `Result` 类缺 getter，Jackson 无法序列化私有字段。
   - 解决：改为返回 `Result` 对象，并给 `Result` 补齐 getter；改完后需**重启 Spring Boot** 才生效。
